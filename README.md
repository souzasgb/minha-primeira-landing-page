# Minha Loja de Tecnologia 💻

> Um projeto de e-commerce desenvolvido com o objetivo de aprimorar e consolidar conhecimentos fundamentais em **HTML5** e **CSS3**.

---

## 📌 Sobre o Projeto

Este site foi criado como um projeto de estudo para praticar a estruturação semântica de páginas web (HTML) e estilização com layouts modernos, incluindo o uso de **Flexbox** e **Design Responsivo** para diferentes tamanhos de tela (CSS).

⚠️ **Aviso:** Este projeto é apenas para fins de aprendizado/portfólio e não representa uma loja real.

---

## 🚀 Tecnologias Utilizadas

Atualmente, o projeto utiliza apenas tecnologias de front-end estático:
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização, Flexbox e Responsividade)

---

## 🔮 Próximos Passos (Roadmap)

Como o foco inicial foi dominar o design e a estrutura visual, o projeto está pronto em HTML/CSS. No entanto, futuramente pretendo evoluí-lo adicionando **JavaScript** para implementar funcionalidades dinâmicas, tais como:
* [ ] Carrinho de compras interativo
* [ ] Sistema de filtros de produtos
* [ ] Simulação de finalização de compra / cupom de desconto

---

## 📂 Como Executar o Projeto

1. Faça um clone ou o download deste repositório.
2. Abra a pasta do projeto no seu editor de código favorito (como o **VS Code**).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência, ou utilize a extensão **Live Server** para visualizar as alterações em tempo real.
